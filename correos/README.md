## 🚀 Cómo Implementar los Correos

### En plataformas de Email Marketing (Mailchimp, Klaviyo, Brevo, HubSpot, etc.):
1. Crea una nueva campaña y selecciona la opción **"Pegar código HTML"** o **"HTML personalizado"**.
2. Abre el archivo `.html` correspondiente (o cópialo desde `correos/index.html`).
3. Reemplaza los campos dinámicos:
   - `{{nombre_contacto}}` ➔ Etiqueta de nombre de tu plataforma (ej: `*|FNAME|*` en Mailchimp, `{{ contact.firstname }}` en HubSpot).
   - `{{nombre_empresa}}` ➔ Etiqueta de compañía de tu CRM.
4. El enlace de cancelación en el footer se puede vincular a la etiqueta de *Unsubscribe* nativa de tu plataforma (ej: `*|UNSUB|*`).

### En herramientas de Prospección Fría B2B (Instantly, Lemlist, Smartlead, Apollo):
1. Puedes usar los textos y estructura de los correos **01 (Primer Contacto)**, **02 (Migración CIF a FOB)** y **07 (Reactivación)**.
2. Puedes insertar el código HTML o extraer los párrafos persuasivos para secuencias en texto enriquecido.
